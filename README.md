# Unbelievable Cat — releases

Download builds of **Unbelievable Cat**, a native macOS desktop pet by Unbelievable Digital.
(The source code lives in a private repository.)

## Install

1. Download **[UnbelievableCat.zip](https://github.com/unbelievable-digital/unbelievable-cat-releases/releases/latest/download/UnbelievableCat.zip)** (latest version).
2. Unzip it and drag **Unbelievable Cat** into **Applications**.
3. Open it. The app is signed with Developer ID and notarized by Apple.

Requires macOS 14 Sonoma or later.

## Updates

The app checks for updates automatically (and via **Check for Updates…** in its menus) using
[Sparkle](https://sparkle-project.org). Every update is EdDSA-signed; `appcast.xml` in this repository is the
update feed.
